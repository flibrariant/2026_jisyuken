## 1万円クラファン（図書予算の決め方アプリ）

公開ページ: https://flibrariant.github.io/2026_jisyuken/books/

読みたい本を帯文つきで登録し、一人3,000コインを出資して、本物の予算1万円の枠を奪い合うページです。
定価に出資が届いた本が「確定ライン到達」になり、1万円に収まる組み合わせを自動で提案します。

参加は任意で、名前を入れて出資した人だけが参加者に数えられます。
最初からAI関連の候補9冊（`books/Code.gs` と `books/index.html` の `SEED_BOOKS`）が並んでいて、候補の追加も自由です。
初期候補を変えるときは両方のリストを揃えて直してください（共有モードでは `books` シートを初めて作るときにだけ入ります）。

URLを開いただけでは「お試しモード」（各自の端末にだけ保存）で動きます。
班で共有するには、Google Apps Script を一度だけ設置します。

### 設置手順（幹事が1回だけ）

1. Googleスプレッドシートを新規作成する（名前は何でもよい）。
2. メニュー「拡張機能」→「Apps Script」を開き、エディタの中身を `books/Code.gs` の内容で丸ごと置き換えて保存する。
3. 必要なら `SETTINGS` の `budget`（予算）、`coins`（一人のコイン）、`deadline`（締め切り日、例 `'2026-11-07'`）を書き換える。
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   「次のユーザーとして実行」は **自分**、「アクセスできるユーザー」は **全員** にしてデプロイする。
   初回はアクセス許可の確認が出るので承認する。
5. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec`）をコピーする。
6. `books/index.html` の `const API = '';` にそのURLを入れてコミットする。
   コミットせずに試すなら、`https://flibrariant.github.io/2026_jisyuken/books/?api=そのURL` でも動く。

`SETTINGS` を変えたときは、「デプロイ」→「デプロイを管理」→ 編集 → バージョン「新バージョン」で再デプロイする（URLは変わらない）。
出資や候補はスプレッドシートの `books` / `pledges` シートに溜まるので、いたずらや間違いはシートを直接直せば反映される。
