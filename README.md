# 2026_jisyuken

QommonsAI自主研の班ワークで使用する、プロンプトコピー用の静的ページです。

公開ページ: https://flibrariant.github.io/2026_jisyuken/

このリポジトリには公開用ページのみを置き、問いのタネボード、分析資料、企画書は含めません。

## 本の銀河（おすすめ本を浮かべて「読みたい」を集めるページ）

`books/` フォルダ。暗い空間に表紙が球状に浮かび、なでて回し、タップすると詳細が出ます。
「読みたい」は一人3冊まで。多く集めた本ほど中心に寄って光ります。誰でも「この本いいよ」を足せて、
書名かISBNで検索すると表紙・著者・定価を自動で持ってきます（Google Books と openBD）。
最初から30冊（AI関連と、自主研向けのおすすめ本。`books/seed.json`）が浮かんでいます。
予算1万円で買う本は、「読みたい」の集まり方を見て決めればOKです。

- 3Dが動かない端末では自動で2Dの表紙グリッドになります（右下で切り替えも可）。
- `vendor/three.min.js` は同梱しているので、外部CDNには依存しません。

### 置き方（XServer などPHPが動くサーバー）

1. `books/` フォルダを丸ごと、サーバーの公開ディレクトリにアップロードする
   （例: `public_html/books/` → `https://atpopz.com/books/` で開ける）。
2. 初回アクセスで `books/data/` が自動で作られ、SQLite（`books.sqlite`）と表紙キャッシュが溜まる。
   作られない場合は `books/data/` を手で作り、パーミッションを 755（ダメなら 775）にする。
3. 表紙や定価は、ページが開かれるたびに数冊ずつ自動で補完される（最初の数回の表示で揃う）。

設定は `books/api.php` 先頭の定数で変えられます（`HEARTS`＝一人の「読みたい」数、`MAX_OBI`＝ひとことの字数）。
いたずらや間違いは `books/data/books.sqlite` を SQLite のツールで開いて直せます（`books` と `votes` の2テーブル）。
全部やり直すなら `books/data/` を消せば、次のアクセスで `seed.json` から作り直されます。

### GitHub Pages 上での挙動

GitHub Pages では PHP が動かないため「お試しモード」（各自の端末にだけ保存）になります。
URL の末尾に `?api=https://atpopz.com/books/api.php` のように付けると、別サーバーの API を使えます。
